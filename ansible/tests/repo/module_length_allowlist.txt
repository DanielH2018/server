# Modules over their code-line cap.
#
# Format: `<repo-relative-path> <max_code_lines>`, one line per file, in `LC_ALL=C sort` order
# (codepoint order, which is what Python's own `sorted()` gives). Caps are 450 code lines for
# a module and 400 for a test module; a line here raises the bar for that one file. An entry may
# only fall or be deleted -- ansible/tests/repo/test_module_length_ratchet.py enforces that
# against origin/master. A file back at or under its cap must lose its line; the list records
# remaining work and the conjoined modules below, nothing else.
#
# A path may be ADDED when origin/master does not track the file (it is new, or renamed),
# when the same commit changes the guard itself and does not edit the file (a widened rule
# finds files that were always over), or when the line ends with a stated reason:
# `<path> <max>  # conjoined: <why>`. The reason names one line count at most: the max it
# approves. The earlier raises are in the commit history, not on the line.
#
# DECIDED: the cap prompts a decision; it does not force a split (#3661, operator ruling
# 2026-10-09). Split a module over the cap when each piece reads alone. When every split
# would leave a piece conjoined with its parent, so that it calls methods only the parent
# defines or copies a literal it may not import, list the module with a `conjoined:` reason
# instead. The reason has to be on the entry's own line. A conjoined entry rises only in a
# diff that rewrites its reason to name the new max, so growth past it restates the decision.
# Why: such a split adds an interface and hides nothing, and each one made here added a
# module, often a copied literal, and a test comparing the copies. What is given up is that
# every long module awaits a split; what is kept is that every long module states why it is long.
# docs/python-code-organization.md has the long form.
#
# A code line holds a token that is neither a comment nor part of a docstring
# (`code_lines` in ansible/tests/_ratchet.py). Blank lines, comments and docstrings are free.
# `uv run python scripts/dev/tighten_ratchets.py --tighten` lowers each entry to its file.
